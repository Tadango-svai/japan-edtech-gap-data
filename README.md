# Japan EdTech Gap Data

This repository contains structured data and case studies highlighting the 'information asymmetry' in Japanese education technology adoption.

## Why?
Many Japanese schools struggle with tech integration due to lack of standardized failure case data. This project aims to close that gap.

## Features
- Anonymized case studies of tech integration failures
- Data points on 'information gap' metrics
- Analysis of why certain tools succeed/fail in Japanese contexts

## Usage
See `data/` folder for CSV exports. See `analysis/` for Jupyter notebooks.
